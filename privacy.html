Privacy policy

Last updated 24 October 2026.

Stickman Uploader is a personal tool used only by its owner to manage the owner's own YouTube channels.

Data we access

With the owner's permission through Google sign-in, the tool accesses the YouTube Data API for the owner's own channels: uploading videos, editing video and channel details, and reading upload status. It requests the YouTube scopes youtube.upload and youtube.

How data is used and stored

Sign-in tokens are stored only on the owner's computer. The tool keeps no copies of channel data on any server and has no database. It does not collect personal data from viewers or from anyone else.

Sharing

No data is sold, shared or transferred to third parties. Data is sent only to Google/YouTube to perform the actions the owner requests.

Children's privacy

Some channels managed by this tool publish content made for kids. The tool never collects any information from viewers, including children.

Google API Services User Data Policy

Stickman Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is also subject to the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
